# Advance Hardware website

English and Arabic, works on phones, no monthly fees, no build step.
Customers pick items, build a list and send it to you on WhatsApp. No prices on the site; every item says "Ask for price".

## Pages
`index.html` (home) · `products.html` · `trade.html` · `about.html` · `contact.html` · `credits.html`.
The pages are generated by `python3 tools/build_pages.py`. Edit that script (not the .html files), then run it.
Add `?lang=ar` to any address to open the Arabic version, for example `products.html?lang=ar`.

## Before going online: check these
1. **Products marked "check"** in `data/products.csv` are common hardware items we added as suggestions
   (safety glasses, ear plugs, anchors, wall plugs, rivets, drill bits, discs, Allen key sets, spanners,
   cable ties, tape, silicone, spray lubricant). **Delete the rows you don't sell**, and clear the `check`
   column for the ones you do. `python3 tools/build_products.py` lists them every time it runs.
2. **Sizes** for each product are a starting list. Correct them to what you really stock.
3. **Photos**: the photos are free-licence images from Wikimedia Commons (credited on `credits.html` and in
   `docs/image-credits.md`; the credits page must stay online while they are used). Replace them with our own stock
   photos when ready (`docs/photo-shot-list.md`), using the same look (`docs/image-recipe.md`).
4. **Google link**: put your Google Maps share link in `googleUrl` at the top of `assets/app.js`
   (and in `sameAs` in `tools/build_pages.py`, then run it).
5. **Reviews**: paste 2–3 real Google reviews into `data/reviews.json`, word for word, then run `python3 tools/build_pages.py`.
   Never write our own. Format (one entry per review; `lang` is `en` or `ar`):
   ```json
   [{"name": "First name", "date": "Oct 2026", "stars": 5, "text": "Exact words from Google", "url": "link to the review", "lang": "en"}]
   ```

## Change the products
1. Open `data/products.csv` in Excel or Numbers. One row per product:
   - `icon`: bolt, screw, nut, washer, rod, tools, glove, anchor or tape
   - `category_en`, `category_ar`: category name in English and Arabic
   - `name_en`, `name_ar`: product name in English and Arabic
   - `sizes`: sizes separated by `;` (for example `M6;M8;M10`)
   - `options`: types/finishes separated by `;`, each written `English|Arabic` (for example `Zinc plated|مطلي زنك`)
   - `grades`: strength grades separated by `;` (for example `8.8;10.9;12.9`)
   - `check`: write `check` if not yet confirmed; leave empty when confirmed
2. Save as **CSV UTF-8**, then run `python3 tools/build_products.py`.

## Change opening hours
Only in `data/hours.json` (UAE time). A closed day is an empty list, e.g. `"0": []` for Sunday; it then shows "Closed".
Run `python3 tools/build_pages.py`: the header badge, the 7-day table, the footer, the open/closed sign,
Google's structured data and the contact page description all update from that one file.
Keep Google Business Profile hours the same.

## Change phone numbers, Google link or hero video
At the top of `assets/app.js` (`SITE = { ... }`).

## Add the hero video
Put `hero.mp4` (1080p), `hero.webm` and `hero-720.mp4` (phones) in `media/`, each under 3 MB, then set
`heroVideo: { mp4: "media/hero.mp4", webm: "media/hero.webm", mobile: "media/hero-720.mp4" }` in `assets/app.js`.
Phones set to "reduce motion" see the still image instead.

## Change any text
All English and Arabic text is in `assets/i18n.js`.

## Look at it on your computer
In this folder run `python3 -m http.server 8090`, then open http://localhost:8090

## Put it online (free): not done yet
Any static host works (Cloudflare Pages or Netlify: drag and drop this folder). They also compress and cache the files,
which makes the site faster than on your computer. Then buy `advancehardware.ae` (about AED 125 for the first year),
connect it in the host's settings, and add the address to your Google Business Profile.

## Photos: how they are made
`tools/process_images.py` downloads each photo, cuts out the product (rembg, runs on this Mac), applies one colour grade
and exports WebP and JPEG sizes. Card images: product cut-out on dark steel (4:3). Hero and About: full graded photos.
The recipe is in `docs/image-recipe.md` and credits are in `data/photo-credits.json`.

## Where enquiries come from (WhatsApp "Ref" line)
Every WhatsApp message sent from the site ends with a line like `Ref: website/home/hero` (page / button).
Places: header, menu, mobile-bar, footer, hero, grades, how-to-order, find-a-size, products-photo, product-search, my-list, trade-form.
Use these links outside the site so the message also says where the visitor came from (`· via …`):

| Where | Link |
|---|---|
| Google Business Profile (website field) | `https://YOUR-SITE/?src=google` |
| QR codes (shop counter, delivery bags, invoices) | `https://YOUR-SITE/?src=qr` |
| Instagram bio | `https://YOUR-SITE/?src=instagram` |
| Facebook / TikTok / business card / flyer | `?src=facebook`, `?src=tiktok`, `?src=card`, `?src=flyer` |

Example message ending: `Ref: website/products/my-list · via QR code`. The source is remembered while the visitor browses.
